Extending Lens DoF with chromatic aberration [Part 2 - Use the off-the-shelf lens]

Aaron
2024-04-13
optics, zemax

Objective

Without sufficient experience and resource in lens fabrication, I want to seek designs with off-the-shelf lens that one can directly purchase from online vendors, such as Thorlabs and Edmund Optics. What will be an efficient pipeline to optimize via Zemax and iterate through online lens catalog? The performance is likely to drop due to reduced degree of freedom. But maybe we can still find a acceptable design.

Design

  1. Similar to previous post, configure the system properties in the System Explorer as below. Start from a symmetric two singlets layout with initial material PMMA. Initialize the sytem with merit functions targeting spot size and effective focal length (EFFL). Note that the spot size should be opmimized for the primary wavelength only, because the other wavelengths are defocused by design. The thickness constraints are: minimal air thickness of 0 and minimal glass thickness of 2 mm.

    Property Value
    Aperture Type Entrance Pupil Diameter
    Aperture Value 12.0
    Fields 0, 2.121, and 3 deg
    Wavelengths 485, 515(primary), and 535 nm

  2. Based on the common glass types from Edmund Optics and Thorlabs stock lens, let’s create a customized Materials Catalog:

    • Open Materials Catalog
    • Choose an existing Catalog from the drop-down, e.g. AMTIR.AGF
    • Click Save Catalog As to create a new catalog
    • Use Cut Glass to delete materials
    • Use Copy Glass and Paste Glass to copy materials from the other existing catalogs. Or type in the material properties and create one ourselves.
    • In the System Explorer, make the customized catalog the only one in use.

  3. In Lens Data, change the Materials solve to Substitute. Add chromatic aberration-related Operands in Merit Function. Run Hammer Current to get the baseline model. We will try to approximate the design with off-the-shelf lens.

  4. The use of N-SF6 can be attributed to its high dispersion, which helps increase the chromatic focal shift. From this glass table we can find out that it has the lowest Abbe number among the materials we seleced. After browsing Edmund Optics, I found that the maximal focal length for N-SF6 is 50 mm, a High Precision Aspheric Lens. I replaced the first lens in our layout with this one. After a Hammer Current with the remaining variables, the optmized design shows degraded Merit Function (from 0.00029 to 0.00326).

    When replacing with off-the-shelf lens, we should match according to material, shape (plano-convex, plano-concave, positive meniscus, negative meniscus, etc.), and optical power. Here I also tried switching with the second lens instead of the first one in the baseline design, as well as reversing the elements. We can choose where to continue based on the best possible merit function (after Hammer optimization.)

    P.S. When picking stock lens from vendors, Edmund Optics provides filters when searching. Choose the desired material, range of effective focal length, and go through the results one by one for best option. Thorlabs doesn’t have searching filters yet. We can go to specific lens types, such as positive meniscus lens, and check whether there are lens with desired materials. In my experience, the Stock Lens Matching tool embedded in Zemax doesn’t help in this case, where chromatic abberration needs to be considered. Maybe it’s better for monochromatic design.

  5. The Hammer Optimization changed the second lens to a negative meniscus with N-SF5, which cannot be found on Thorlabs or Edmund Optics. I turned to search for a plano-concave lens, which led me to LC2679. After replacing the second lens in the baseline model, the Zemax cannot optimize to a optimal. The algorithm somehow got trapped and failed to find proper lens spacing for correct total effective focal length. To set a good initialization point, we need to roughly calculate the spacing between two lens.

    Using the Gullstrand’s Equation, we can calculate that we need a spacing of 28 mm for a 50 mm lens and a -30 mm lens to reach 180 mm effective focal length. Set the thickness of surface 2 to 15 mm and surface 3 to 0. Run Optimize! again for a correct result.

  6. I changed the material of second lens to N-BK7. Set the radius and thickness back to variables. Run Optimize! again. This time, the optimzied lens has a more similar shape to plano-concave lens. With material N-BK7 comes much more lens candidates. It’s thus easier to find off-the-shelf lens with similar focal length (Calculate the focal length by taking surface 4 and 5 to a separate Zemax window and we can get f=-41 mm). I found 45-920 from Edmund Optics. Using this stock lens, we have a slightly better design compared to Step 5.

    Similarly I can also tried other materials. And from all optimization results I can choose the best according to the performance and stock lens availability.

Conclusion

We have attempted to substitute the components of our previous design with stock lens from online vendors. These off-the-shelf lens degrades the system performance, but avoids lens fabrication and allows quicker prototyping.
