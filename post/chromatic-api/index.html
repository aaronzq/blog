Extending Lens DoF with chromatic aberration [Part 3 - Zemax programming API]

Aaron
2024-04-17
matlab, optics, zemax

Objective

Zemax doesn’t support customized analysis pipeline very well, for example, calcluating three dimension PSF. I assume that it’s because of Zemax mainly being oriented for traditional lens design where compound lens group and 2D images are involved. Now since we slightly deviate from tradition and try to use aberration to image multiple depths, Zemax can become inconvinient. My purpose is to calculate the PSF at different depths. All the wavelengths within our spectrum of interest will contribute to this PSF, except that most of them will be blurred out and a few will focus. To achieve this, I need to run PSF analysis at every depth and wavelength, and then export the raw data to MATLAB to combine them incoherently along the wavelength axis. This process involves a lot of repetitive operations. Therefore, we intend to use the Zemax APIs to control Zemax and automate the process through programming.

Steps

  1. The APIs will basically ‘click’ buttons in Zemax for us. It edits lens data, runs optimize and runs analysis but it needs to operate on an existing Zemax project. So the first thing is to create one.

    We have designed a tube lens with enhanced axial chromatic aberration. Now I can use it with an objective (infinity corrected) so a microscope is constructed. In the Zemax, I used a paraxial lens to represent a 20X0.5NA dry objective. The field of view is defined by dividing a typical sCMOS sensor size (13 mm) by the magnification, which is 0.325 mm. I set the distance between object and objective as the only optimizable variable. It adjusts the depth of the ‘sample’. After defining the merit function on spot size, and through Optimize!, we can find the focus under current wavelength. After trying multiple wavelengths, we can observe the focus range for 495-535 nm is around 15 um.

  2. We can use Analyze-PSF-FFT PSF to calculate the point spread function (PSF) of the system. However, the PSF is subject to both the wavelength and the object’s axial location. We are going to write a script to iterate through these two variables to characterize all PSFs.

  3. In tab Programming, find MATLAB-Standalone Application. I got a template Matlab script by clicking it.

    The script contains multiple pre-defined functions. Some of them load the Zemax’s DLL and connect to the Zemax application installed on this PC. What we need to take care of is the BegingApplication(The Application, args). It’s been left empty and we need to write the custom codes inside it. The definitions of APIs as well as examples can be found in the manual (Programming-ZOS-API Help).

  4. Use function LoadFile to import the Zemax file that we created at step 1.

  5. Access the surfaces through function LDE.GetSurfaceAt(surface id). Thickness member properties can read us the thickness of the surface. And we can edit the thickness by simply assigning a new value. Similarly, we get access to the wavelength by SystemData.Wavelengths.GetWavelength(1). After choosing the primary wavelength 515 nm, we can run a local optimization to find the sharp focus at this wavelength. This will be our starting point: microscope is focused at the primary focal plane, what we need to do next is to ‘translate’ the sample axially and observe response on the image plane. Note that the merit functions, variables were imported when we loaded the Zemax file. Although we can define/change them here using APIs, it’s also convenient to define them using Zemax software before importing them.

Conclusion

After collecting all PSF data, we can incoherently sum them along wavelength for a given one depth. This will synthesize a widefield PSF at that depth. Repeating the summation for each depth will eventually gives us the 3D PSF of the fluorescent microscope. If the PSF stays sharp through a large depth range, we get a extended DoF microscope.
