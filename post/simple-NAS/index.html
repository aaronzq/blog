Data back-up server using my 20-year-old desktop - Here are some notes.

Aaron
2025-01-25
electronics

I came home with a few portable harddrives of personal photos, videos to back up. The commercial NAS came across my mind but they seem too expensive. After all I don’t think I really need RAID array, media center, user management or other fancy functions. The most important thing for me is simply a large storage to keep a second copy of all my data (like 5 TB this time).

I happened to find the old desktop I used to play Starcraft and Plants v.s. Zombies on. All those fun and excitement and good memory. But it has a Pentium E5400 @ 1.5Ghz CPU and 4 GB RAM, which totally makes sense since man that was almost 20 years ago. I wanna try setting up as a linux server and using samba for simple data sharing.

I installed Manjaro (KDE Plasma) because I heard some people saying it’s light-weighted to the hardware and friendly to beginners. And I installed a new Seagate IronWolf 8T harddrive to the computer.

Below are some notes:

Where to install the KDE Partition Manager

Manjaro KDE should come with a GUI-based disk partition tool. However I chose the minimal version when installling Manjaro due to limited size of my USB stick. Possibly for this reason the KDE Partition Manages was skipped. In this case, we can go the Manjaro Hello in the Start menu. There we can install those default apps included in the full Manjaro installation.

Automatic mount of disk

  1. Find the uuid by ls -l /dev/disk/by-uuid of the new disk. If the Device’s name is unknown, we can use sudo fdisk -l to list all disks.

  2. Append a new line to /etc/fstab. We can edit the file using nano: nano /etc/fstab. And add a new line at the bottom: /run/media/Data is the mounting point which we can create ourselves; btrfs is the file system format, which should be decided during disk partition; 0 0 means no disk check during system boot up.

Ladder (for Github access)

I think the easiest way to give this old desktop, namely server, a ladder is to use ssh. We need a local computer, such as our daily laptop, which already has access to the websites blocked by GFW, for example, using proxy tools like clash. We can open a channel between the server and the laptop using ssh and ask the server to talk to the internet through the laptop rather than directly to the router.

The server_port is the port used by the server to forward the network traffic to (7001~8999, as long as it doesn’t conflict with existing ports) and the local_port is the port used by local computer’s ladder. For clash, the local_port is usually 7890. Note that we should ‘Allow connect from LAN‘ in clash.
