Extended DoF with chromatic aberration

Created2024-03-24|Updated2024-04-06
|Post Views:

Objective

Utilize axial chromatic aberration to design a lens with extended depth of field for fluorescent microscope.

Rationale

In contrast to natural scene photography, fluorescent microscopy focuses on the spectral channels of fluorescent proteins (e.g., GFP, dsRed). Various wavelengths within the emission spectrum convey similar information, accumulating to yield a single pixel value and produce a grayscale image. This suggests the potential for utilizing wavelengths to multiplex signals across other dimensions, such as depth.

The depth of field (DoF) dictates the range of depths within which objects can form sharp images on the camera sensor. A smaller lens aperture (i.e., larger F/#) results in a larger DoF. However, according to diffraction theory, reducing the aperture size leads to larger spot sizes, or in other words, diminished spatial resolution. To attemp to break this trade-off, let’s imagine a large aperture lens that has slightly different focal length at different wavelength. Therefore, even though the DoF is shallow at single wavelength, we can focus on other depth by tuning the wavelength. Instead of controlling axial chromatic aberration, we take advantage of it.

Meanwhile, we need to suppress the other aberrations, especially the lateral chromatic aberration, which gives different image magnification for different colors, and in our case, for different depths. Since the Seidel coefficient of lateral chromatic aberration has an odd order of chief ray height, it can be corrected by an symetric system. And it does not apply to axial chromatic aberration. So we can have an inital design where the stop is put in the middle.

Specification

Design a tube lens for Olympus objective (such as 4X0.13NA, 10X0.3NA, 20X0.5NA, 40X0.8NA). Exit pupil size ~ 10.8 mm. Inifinity space angle -2~2 degree. For 4X, 4.8 mm image side focal shift will have 300 um DoF at object side.

Design

  1. In the System Explorer, set the Entrance Pupil Diameter to 12 mm. And use the Field Data Editor’s Field Wizard to generate three Fields by Equal-area Y Fields from 0 to 3 degree. Choose the primary wavelength as 515 nm. Next, in the Lens Data windows, lay out a two-lens setup with stop in between. Set all radius and thickness to variables. For the lens material, we can start with PMMA.


2. Use Optimization Wizard to insert operands on Spot size and set Boundary Values for thickness.


And add operand EFFL (target: 180 mm) to control effective focal length. Search the Zemax HELP page for definitions of operands.


3. Local optimization so that we can get a focused sytem with focal length 180mm. In order to run Global optimization, the system should have at least the approximate focal length desired.


4. Now we need to set boundary wavelengths (485nm, 535nm) to define chromatic aberration. Add operands based on these wavelengths: LACL computes the lateral chromatic aberration at the outmost field by tracing chief ray height at sensor plane. Here we want to find the spot centroid. So we use CENY instead to find the centroid Y position (skipping X due to radial symmetry) and mannually calculates the difference DIFF between each wavelength. Let’s minimize these difference to zero. The AXCL calcutes the chromatic focal shift and we use OPGT and OPLT to confine it between 4.8 mm and 5 mm. Lastly, the total length of the lens group TTHI is constrained less than 45 mm. But let’s set the weight to 0 and leave it for later.

  1. In the Lens Data, set the Material solve type to Substitute. Run Global Search for possible designs.

  1. Enable the contraint on total thicness by set the weight of operand 15 OPLT to 1. In the Lens Data windows, set the Clear Semi-Diameter to half inch and run a Hammer Optimization. Click Automatic in Hammer Optimization window after finihsing Hammer to run a local optimization on current design.

  2. Evaluate the performance by checking the Spot Diagram, Chromatic Focal Shift and Lateral Color. The spots from various wavelengths are colocalized. The focal shift meets our specification.


Selecting only the primary wavelength, that are currently focused, show spot diagram below diffraction limit.


The ray fan plot indicates the defocus dominates the other unfocused wavelength channel. The focused channel has slight astigmatism and field curvature.

Conclusion

A Zemax practive without considering practical manufacturing and fabrication. Mainly for proof of concept.
